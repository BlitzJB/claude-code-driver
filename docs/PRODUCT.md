# Product context

register: brand

## Users

Node.js developers who build automation, agents or tooling on top of Claude Code and want to use their Claude
subscription rather than API billing. They read the docs on a laptop, often in daylight, with an editor and a
terminal open next to the browser. They judge a library by its guarantees and its code samples, not by its marketing.

## Product purpose

`claude-code-driver` runs the interactive Claude Code TUI inside a private tmux server and gives programs a typed,
streaming view of it. Programs send prompts, read events and the live state, and answer permission requests from code.

## Brand

The reference is tmux's own status line, the green bar along the foot of every session. The mark is a pane with that
bar. One committed accent (status green) on graphite and paper neutrals tinted toward the same hue. Geist and Geist
Mono. Full details in [BRAND.md](BRAND.md).

## Tone

Plain, specific, technical. Say what happens and how it is guaranteed. No slogans, no hype words, no em dashes.

## Anti-references

- The generic developer-tool look: navy or black backgrounds with neon cyan or purple accents and glows.
- Anthropic's own visual identity. The project is independent and must not look official.
- Template landing pages: centered hero, a grid of identical feature cards, gradient headline text.
