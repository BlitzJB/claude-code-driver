# ICR 0008 (WP-08): network + registry normalizers — additive model change and readings of §2.4/§2.8/§3.10

- **Status:** accepted (2026-11-03, WP-08, additive only)
- **Files:** `src/model/observation.ts` (two new optional fields); WP-08's own files `src/channels/{network,registry}/**`

1. **`ObsOrigin` network gets `tunnelSeq?: number`.** §2.4 says "network phases carry a per-tunnel sequence" but no field held
   it. Every `net.tunnel` observation now has `meta.origin = {kind:'network', tunnelId, tunnelSeq}`, with `tunnelSeq` 1, 2, 3, …
   per tunnel (it restarts at 1 if a closed id is ever seen again). Not a de-duplication key (D-42): nothing is de-duplicated.
2. **`net.tunnel` payload gets `alpnH2?: boolean`** (P-NET-18). It is `true` on every phase after the client's ClientHello
   offered ALPN `h2`. **WP-09:** such a tunnel may multiplex several requests. Keep its correlation `confirmed:false` and do
   not assume one request per tunnel.

Readings that consumers (WP-09 `net-correlate.ts`, WP-11/WP-INT wiring) rely on:

3. **Phases.** Only token-A tunnels to `api.anthropic.com:443` whose SNI (when seen) matches get burst phases
   `idle | sending | awaiting | receiving`. Every other tunnel gets only `open | close | error | refused`. `established` → `idle`.
   The first `up` → `sending`. `sending` → `awaiting` when no `up` record came for `sendSettleMs` (250 ms). This is inferred
   from the time of any later record on another tunnel or from the optional `tracker.tick(at, wallAt)`, which L3 may call on
   its poll cadence. The first `down` → `receiving`. A down record with `lastRecordLen === 22` → `idle{endedBy:'terminator'}`.
   This is a hint only (P-NET-29); more down bytes re-enter `receiving`. An `up` while `receiving` → `idle` (no `endedBy`), then
   `sending`. `close` → `endedBy:'close'` for FIN, `'rst'` for RST or error.
4. **Bytes are cumulative per tunnel** (`bytesUp`/`bytesDown`), never per burst. `lastDownAtMono` is the `at` of the last down
   record. `receiving` is re-emitted at most every `refreshMs = clamp(quietMs/15, 250, 1000)`, so `lastDownAtMono` is never
   more than 1 s stale for the core's quiet (15 s) and stalled (25 s) deadlines. The tracker itself never emits quiet or stalled.
5. **Sidecar death** (reserved record, ICR 0004 item 1) → `channel.health{network, down, reason:'sidecarDied'}` (source
   `network`), then `net.tunnel{close, endedBy:'rst', error:'sidecarDied'}` for every tracked tunnel not yet closed (including
   ones that already reported `error`), in tunnelId order.
5a. **`error` is not terminal** (verifier, WP-08 audit): the real sidecar emits `error` on a socket error, then flushes pending
   meter bytes as `up`/`down` records and emits `close` on teardown. After `error` a tunnel's bytes are still counted, but it
   gets no further burst phase (`sending`/`awaiting`/`receiving`/`idle`) until its `close`. WP-09 should treat `error` as
   "this tunnel's current burst failed" and `close` as the end of the tunnel.
6. **Unknowns** (`unknown{channel:'network'}`): a malformed record (`raw.reason:'malformedRecord'`), a non-death record with
   tunnelId 0 (`reservedTunnelId`), and an SNI that disagrees with the CONNECT host (`sniMismatch`, reported once; the tunnel
   is demoted to non-model).
7. **`TunnelTracker` (§2.8) gains `tick(at, wallAt)` and a read-only `size`.** `push(r)` is unchanged. The options are
   `{quietMs, sendSettleMs?, maxTunnels?}`, and `createTunnelTracker({quietMs})` still works as written in §2.8.
   `normalizeTunnelRecords(records, o)` runs a fresh tracker over a recorded stream (for replay).
8. **Registry** (`normalizeRegistry`): `undefined`/`null` → `[]`. An invalid pid or a non-object → one `unknown{channel:'registry'}`.
   Otherwise one `registry` observation with cleaned strings (whole ANSI/OSC escape sequences, C0/C1 controls, bidi overrides
   and zero-width characters removed, trimmed, ≤ 256 chars, empty or wrong-typed
   values dropped), and `meta.claudeSessionId` = `sessionId` (never filtered). `tmux`/`procStart` are not forwarded. Pid identity
   is checked in L3.
